================================================================================
ENVELOPE FORMAT VERIFIED
================================================================================

Wire format:
  OP_RETURN OP_FALSE OP_IF "utxovm" <version> <type> <payload> OP_ENDIF

Example (deployment):
  6a 00 63 06 7574786f766d 01 10 6170706c69636174696f6e2f6a736f6e 4c... <payload> 68

Push data encoding:
  - len < 0x4c: single byte length
  - len <= 0xff: 0x4c + byte
  - len <= 0xffff: 0x4d + 2 bytes LE
